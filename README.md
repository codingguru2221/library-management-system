# Library Management System

## Overview
The Library Management System is a C++ application that allows users to manage books, members, and user accounts. Users can log in, sign up, borrow and return books, and search for books by title or genre.

## Features
- User registration and login
- Book borrowing and returning
- Search for books by title
- Display books by genre
- Load and generate sample books from files
- Clear screen functionality for better user experience

## Requirements
- C++11 or later
- A C++ compiler (e.g., g++, Visual Studio)

## Installation
1. Clone the repository or download the source code.
2. Open the project in your preferred C++ IDE or text editor.
3. Compile the `main.cpp` file.

## Usage
1. Run the compiled executable.
2. Follow the on-screen instructions to log in or sign up.
3. Use the menu options to manage books and members.

## File Structure
- `main.cpp`: The main source file containing the implementation of the Library Management System.
- `users.txt`: A text file that stores registered user credentials.
- `books.txt`: A text file that stores book information.
